# 🎂 Happy Birthday Animated Greeting Card

Vercel болон гар утас (Mobile First)-д бүрэн тохируулагдсан интерактив төрсөн өдрийн мэндчилгээний веб аппликайшн.

## ✨ Онцлогууд (Features)
- 🎬 **Кино шиг гэрэл унтраах & 3, 2, 1 тоолох анимэйшн (Lights Out & Countdown Blow)**:
  - "Лаагаа үлээж хүслээ шивнээрэй!" товчийг дарахад ар талын бүх зүйлс харанхуй болж, **өрөөний гэрэл унтарсан мэт зөвхөн бялуу ба 5 лаа алтан туяагаар гэрэлтэнэ**.
  - Дэлгэц дээр *"Хүслээ шивнээрэй... 💫"* гэсэн бичигтэй хамт **3... 2... 1... Үлээлээ! 💨** гэж тоолон дууны эффект дуугарна.
  - Лааны дөлнүүд унтарч, харанхуйд лааны утаа савсан замхарна.
  - Үүний дараа өрөөний гэрэл буцаж асаж, дэлгэц бүтэн сэргэн ялалтын аялгуу болон дэлгэц дүүрэн салют, конфети цацарна!
- 🎂 **Минимал, энгийн чамин бялуу (Minimalist Cake with 5 Candles)**:
  - Пастел ягаан/кремэн суурьтай, цагаан керамик тавагтай, дээрээ 5 ширхэг нарийхан лаатай.
  - Лаа тус бүр өөрийн давтамжаар зөөлөн анивчин гэрэлтэнэ.
- 📱 **Гар утасны бүрэн зохицол (Mobile-First & Vercel Ready)**:
  - `100dvh` хэмжээс, Mobile Bottom Sheet тохиргооны цонх.
  - Утаснаас хуваалцахад Native Web Share API-аар Messenger, Instagram, Telegram-аар шууд илгээнэ.
- 🎈 **Дэгдэх бөмбөлгүүд**: Дарж "POP!" дуутай хагалах.
- 🎵 **Арын ая (Background Music)**: `sad_version.mp3` дууны долгионы анимэйшнтай товчлуур.
